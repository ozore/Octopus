Hello,

Both are self-serve, and here is what each does.

Export
- Settings, Data, Export everything. Any member can request it; it is their compliance data too, and the request is logged.
- You get one zip: CSV files for technicians, licenses, deadlines, CE records and alerts, a folder with every document you uploaded, and one JSON file holding everything. Every license row carries its citation columns, so the source and last-checked date travel with the data.
- The download link is emailed and expires after 7 days; request another if it lapses. Exports are limited to three per organization per day.

Deletion
- Settings, Data, Delete organization. Owners only, and you type the organization's name to confirm.
- Deletion runs 7 days after the request. Every owner is emailed, and it can be canceled at any point in those 7 days.
- If a subscription is active we cancel it first, in the same flow, and say so on screen.
- After it runs, no record anywhere carries the organization's id, and any live export link is invalidated.

What we hold: organization and business-contact details, and for each technician the name, license number, license type and dates, plus documents you upload. Nothing else about a technician: no home address, phone, personal email or emergency contact, and never a date of birth, SSN or fingerprint record. Data is stored in the US. The full statement is at /legal/privacy.

If you want me to confirm an export or deletion has completed, reply with the organization name and I will check.
