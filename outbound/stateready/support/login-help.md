Hello,

There is no password to reset. StateReady signs you in with a link emailed to your address, and here is what fixes it nearly every time.

1. Check spam or quarantine for a message from StateReady, and ask whoever runs your mail to allow our sending address if it landed there.
2. Request a fresh link. A link expires 15 minutes after it is sent and works once; the newest one is the one to use. If you asked twice, either link is fine.
3. If the link opens a page that says it is no longer valid, ask for a new one from that page and open it on the device you are using now. Some corporate mail filters open links before you do; if it keeps happening, tell us and we will look at the delivery log with you.
4. To change your sign-in email: Settings, Profile, enter the new address. We send a link to the new address and nothing changes until that link is used.

Requests are limited to five per email address per hour, so if you see "too many requests", wait a few minutes rather than retrying.

If none of that works, reply with the address you are using and roughly when you requested the link.
