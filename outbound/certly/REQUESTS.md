# Certly outbound: requests to the engine owner

**From:** Outbound Copywriter, phase-4 fleet, wave 3. **Date:** 2026-09-04.
Nothing under `outbound/engine/` was edited. Each item below is something the Certly sequences or the
playbook had to write around; the workaround in use is stated so the founder is never blocked on it.

| # | request | why | workaround in use |
|---|---|---|---|
| R1 | Suffix the drafts folder and the approvals file by workbook, as `plan_path` already does (`drafts/<date>-partners/`, `approvals/<date>-partners.json`). | `compose --partners` writes into the same `drafts/<date>/` as the customer batch and overwrites `manifest.json` and `preview.html`; `approve --date` approves every draft in the folder regardless of workbook; `send --partners` then loads every approved draft, logs the customer ones a second time, and only advances partner rows. | The playbook runs partner batches on a day with no customer batch (§4, F12). |
| R2 | A blocking check `from_name_missing` in `compose.check_draft()` when the from-name placeholder appears in the body or the `from_name` field. | The sequences sign with `{{sender.name}}`, which exists in the compose context but falls back to `[SENDER NAME PLACEHOLDER - set OUTBOUND_FROM_NAME]`. Only `from_address`, `postal_address` and `unsubscribe_url` are blocking today, so a batch with the address set and the name unset would be approvable with a placeholder in every body. | The playbook tells the founder not to approve a preview that shows a bracketed placeholder (§3). |
| R3 | A `vendor_band` fact and phrase (OFFER.md §11.1's `{{ESTIMATED_VENDOR_BAND}}`) derived from `portfolio.count` with a documented, sourced mapping. | The godfather email in OFFER.md §11.1 states an estimated vendor count; no such fact exists in `personalise.phrases()` and inventing one would be a number with no source. | The emails describe the vendor file without a count. |
| R4 | A sequence-level way to attach a file or render an env-backed link (`{{app.sample_report_url}}`, `{{app.template_url}}`), with no literal domain (REVIEW.md B-11: `certly.app` is not ours). | OFFER.md §11.2 wants the redacted sample Gap Report attached to follow-up 1 and the segment's requirement template sent with the breakup. The engine is plain text, no attachments, no links. | Both emails ask for a one-word reply ("sample", "template") and the founder sends the file by hand (PLAYBOOK §5). |
| R5 | `opening_sentence()` should not wrap a segment in an article: "I have you down as a residential property management in Dallas, Texas" reads as broken. Suggest "I have you listed under {segment}{ in location}". | 800 of 824 Certly rows fall to the segment-plus-location fallback, so the guaranteed opening is the wrong grammar for the majority. | The four map-reached sequences build that sentence themselves from `{{fact.segment}}` and `{{fact.location}}` behind conditionals; only `plain-intro` still uses `{{fact.opening}}`. |
| R6 | `_split_location` / `STATE_NAMES` renders "Washington, DC" as "Washington, Washington, D.C.". | Visible in the rendered opening for District of Columbia rows. | Left as is; the founder will see it in the preview and can reject those drafts. |
| R7 | A per-step word-budget warning in `check_draft()` (initial 170, follow-up 110, breakup 70) and a subject-length warning at 60 rather than 78. | The wave-3 budgets are enforced only by the scratchpad check in `CLAUDE.md`; a later copy edit can grow an email silently. | Run the render check before every sequence change. |
| R8 | `report` rewrites `REPORT.md` from scratch. Keep a hand-written section (or write the generated part to `REPORT.generated.md`). | The wave-3 section appended to `REPORT.md` will be lost on the next `report` run. | The same content is kept in `outbound/certly/CLAUDE.md` §6. |
| R9 | A reply kind that records a note without moving the stage (for "out of office" and "ask again in March"), and a `next_action_at` override for "not now". | Every accepted kind except `converted` ends the sequence or suppresses the row; the playbook has to use the founder's calendar for "not now" and record nothing for out-of-office. | PLAYBOOK §5. |
| R10 | A Certly-side rule that the render of `{{org.name}}` is checked against the banned status words. | One workbook row is named "ALL Covered Contractors Corp"; any sequence that prints `{{org.name}}` prints "Covered". It reaches `godfather-gc`, which does not print the name, so nothing ships with it today. | Noted in `CLAUDE.md`; `partner-intro` and `plain-intro` are the only sequences that print `{{org.name}}`. |
