Hello,

There is no password to reset. WageLens signs you in with a link sent to your email address each time, or with the six-digit code in the same message typed into the tab that is waiting for it.

If the message has not arrived:

1. Check the address. It has to be the one your organisation signed up with. The sign-in page shows the same confirmation whether or not an address is known to us, so a typo looks like a delay.
2. Look in spam or quarantine. If it landed there, ask whoever runs your mail filter to allow our sending address.
3. Request a fresh link. Each link works once and expires. Opening it in a different browser from the one you asked in is fine: you land on a Sign in button and press it.

If none of that works, reply with the address you are using and roughly when you requested the link, and I will check our side.
