# Tri des 35 candidats par le filtre en sept questions (orchestrateur, 7 septembre 2026)

Le fondateur a délégué le tri. Une réponse non à une question = pas de creusement. La question 5 se lit avec l'IA comme
co-développeur : le code n'est pas le blocage, ce sont les marchés publics, les grands comptes à cycle long, le terrain
lointain et les capacités supposées.
